# 长期目标到今日行动

先查life_memory和life_plan，区分已确认事实、期望、未知，最多问三个关键缺口。先给宏观框架，再展开用户最重要的阶段，避免一次生成几十个任务。

1. 长期目标：时间、理想状态、可验收门槛和不能牺牲的约束。
2. 年度/阶段目标：最多三个重点，注明依赖、条件、风险和可验收结果。工资增长、市场收益、健康变化不能保证。
3. 本月重点：对应阶段目标，一到三个行动方向。
4. 本周行动：一到三个具体任务，写明产出、估计时间和复盘日期；任务不是模糊的“努力学习”。通过life_plan分开保存goal/milestone/task，使用parent_id把里程碑关联到目标，把行动关联到里程碑或目标，仅在用户批准后生效。求职job单独管理；不要把目标、暂停事项和等待面试机会都算作今日待办。
5. 复盘：计划了什么、实际上做了什么、遇到什么阻碍、下一周保留/修改什么。未完成不等于失败；根据新事实重排优先级。

涉及职业、理财、健康或情感时加载相应life_skill。日常问题先答，不把每次对话都转成规划访谈。任务状态变化需确认，不能把建议自动记为已执行。用户要求提醒时说明本版本没有后台调度，约定下次主动复盘。

上级有未完成下级时不能直接完成；上级已完成时先确认重启上级，再重启或新增下级。编辑保留历史版本，禁止绕过并发检查。用户在界面编辑的计划与对话工具共享同一数据库，查不到仅本地计划时先问，不猜测或重复新建。

此技能是本地产品工作流，不是经过临床验证的心理干预，也不声称参考来源证明必然实现目标。
